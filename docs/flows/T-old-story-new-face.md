# Flow T: Old story, new face

**Shape:** a famous modern scene → a phenomenon named after an old story → tell the old story → map the modern figure onto it → one measured result → return to the scene, then hand a question back

**Beats** (scene ids `bun run new` scaffolds): `hook, myth, figure, evidence, payoff` · spoken numbering: **no** · has a turn: **small** · fits visuals: b-roll, illustrated-scene, archive-plate

## When to use

A modern figure or scene that **re-enacts a myth or classic story**, and a phenomenon
named after that story. Example: a film's physicist watching the first bomb, joyless
in victory → the Prometheus "curse of knowledge" → the myth → the physicist "brought
fire" too → a survey finding higher anxiety among very high-IQ people.

## Rules

- **Hook: the modern scene and the odd feeling in it**, then the name.
- **Tell the old story in one scene**, only the parts that map: what was given, what it
  cost.
- **Map explicitly**: "He brought fire back too: …". Every mapped element must be in
  the ledger for the modern side.
- **One measured result**, said plainly, with its weakness respected (§9: a single
  study allows no universal words).
- **Close on the opening scene with the name**, then optionally one question handed
  back to the viewer. Not a moral.

## Traps

- Forcing the mapping: if only half the myth fits, say less of the myth.
- Treating the myth as evidence; it is the lens, the ledger is the evidence.
