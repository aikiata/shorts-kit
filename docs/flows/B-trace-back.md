# Flow B: Trace back

**Shape:** a claim everyone repeats → "who said it first?" → walk back link by link → reach a measurement, or reach nothing

**Beats** (scene ids `bun run new` scaffolds): `hook, origin, link1, link2, link3, payoff, share` · spoken numbering: **no. Count the links instead** · has a turn: **yes** · fits visuals: archive-plate, news-photo, b-roll, gif

## When to use

A viral claim with a **citation chain you can actually walk**. If you cannot walk it,
you are retelling an anecdote and the topic is not ready.

## Rules

- **The documents are the plot, not illustration.** Each link is a real page on
  screen. "A tells; B shows": B is the answer to "this video has too little evidence".
- **Replace the missing numbering with a countable chain:** "this chain has four
  links", and the on-screen marker names each step (§7d).
- Record each link's source with its tier; the listicles you started from are
  candidate-finders, never the source of an on-screen fact (§9).

## Traps

- A link with no real document on screen is not a link, it is a sentence. Check the
  document's licence at the brief, before writing.
- **A chain that ends in nothing** (nobody ever said it) is a valid and often stronger
  ending than a measurement. Do not invent an origin to tidy it up.
- Do not call the steps "links" on screen if the viewer would not (§7d).
