# Flow O: Reading a graph

**Shape:** a character or scene gives the feeling → name the phenomenon → explain it through the scene → place the character on ONE chart → add a second line or point on the same chart → close back on the character and the name

**Beats** (scene ids `bun run new` scaffolds): `hook, character, curve, sketch, points, secondline, payoff, share` · spoken numbering: **no. Positions on the chart replace it** · has a turn: **no** · fits visuals: b-roll, illustrated-scene, text-as-image

## When to use

A phenomenon that **is a place on a chart**: a curve, a threshold, a dip. The viewer
recognises a feeling through a character (a film scene), then sees the chart and can
point at where that character sits. Example: a famous "uncanny" film character placed
in the dip of a 1970 hand-drawn curve.

## Shapes tried and rejected

- *Familiar name before the picture*: the name arrived before the feeling and the
  image, then was explained. Rejected: confusing.
- *Advice dressed as a law*: conclusion held to the end. Rejected: viewers had to
  remember a curve they had not seen.
- *Bare chart reading*: chart first, each sentence points at a spot. Viewers found it
  monotonous: three visual kinds in 68 s, the chart static for 36 s.
- **Chosen: character, then chart.**

## Rules

- **One video, one chart.** More information goes **on the same chart** (a point, a
  second line), never a new chart.
- **The name may come early** only because the feeling already came first, in sentence
  one and on screen.
- **Do not use the metaphor's everyday meaning** against the chart ("a valley you fall
  into"); words like "bottom" and "deep" only while pointing at the line on screen.
- **Never place a point where the fact does not put it.**
- **A sketch is labelled as a sketch** on screen before the narration says it was not
  measured. The curve shows positions from the original, not data.
- One measured result may be **said in words** ("one experiment found…"), no author,
  no year, no sample size.
- Use the character's real face (blurred if disturbing), not a cartoon face, for "the
  thing that is off".

## Traps

- A static chart for half the video. Move the camera along the line (§12), reveal
  points on their words, bring the character's image onto its point.
