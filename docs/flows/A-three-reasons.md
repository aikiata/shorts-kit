# Flow A: Three reasons

**Shape:** hook → reason 1 / 2 / 3 → context → payoff → share

**Beats** (scene ids `bun run new` scaffolds): `hook, reason1, reason2, reason3, context, payoff, share` · spoken numbering: **yes ("reason number one…")** · has a turn: **yes** · fits visuals: any

This is §2's skeleton in its plainest form. It was the source channel's first flow,
and its first six videos all used it.

## When to use

Only when the fact has **three truly independent pillars**. Three reasons where the
third follows from the first two are a chain, and chains belong to B or C.

## When not to use

When you reached for it because it is the default. Ask what shape the fact has first.

## Rules

- One reason per block, **counted aloud**, each with a number. The count tells the
  viewer where they are; that is real retention.
- **The real reason comes last**, in the context block, never in the hook.
- The payoff denies what the viewer believed, then gives the real reason (§1).

## Traps

- **Falling into A by habit.** "Reason number one / two / three" showed up in seven
  videos in a row; at that point it is a mould that forces every fact into the shape
  "reason". A comparison video dressed as A (it was really flow D) read worse than
  it should have.
- A journey narrated as numbered reasons (half C, half A): choose one.
- The counting phrase is exempt from the reused-phrase check because it is
  deliberate; the payoff formula is not.
