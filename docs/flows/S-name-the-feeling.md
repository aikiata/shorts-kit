# Flow S: Name the feeling

**Shape:** a scene everyone recognises makes the viewer feel something → name it (and its translation) → where the image came from → what the word means → why it causes the feeling → the real origin revealed → close: next time you feel it, you'll know its name

**Beats** (scene ids `bun run new` scaffolds): `hook, origin, meaning, why, reveal, payoff` · spoken numbering: **no** · has a turn: **small (the real origin)** · fits visuals: b-roll, text-as-image, illustrated-scene

## When to use

A **feeling with a name** that viewers have had without knowing it has one, carried by
a well-known image or scene. Example: an eerie empty yellow office from an internet
video → "liminal space" → the Latin for threshold → spaces built for passing through,
emptied → the original photo traced to a real building.

## Rules

- **Sentence one: the scene, the viewer's feeling, and what makes it odd** ("…makes you
  uneasy, though nobody is there"). **Sentence two: the name**, in English and in the
  viewer's language if different.
- **Define by pointing**: each part of the definition points at something on screen.
- **Etymology only if it explains** the feeling (threshold → places for passing through).
- **The reveal is a fact**, sourced (where the image really came from).
- **The payoff returns to the opening scene and reuses the name**, so the viewer leaves
  carrying the word. No new idea at the end.
- No experiment retold; one measured result in words at most.

## Traps

- Name before feeling: viewers get a term to memorise instead of a recognition.
- Riddle sentences to make it mysterious; they read as machine-written.
